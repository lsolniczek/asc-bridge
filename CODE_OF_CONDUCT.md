# Code of Conduct

Be respectful, constructive and considerate in issues, pull requests and other
project spaces. Critique code and ideas without personal attacks. Welcome people
with different backgrounds and levels of experience.

Harassment, threats, discriminatory remarks, unwanted sexual attention and sharing
someone's private information without consent are not acceptable.

Maintainers may edit or remove disruptive contributions, close discussions or
restrict participation. Apply these standards consistently, including to maintainers.

To report a concern privately, use a maintainer's publicly listed GitHub contact
method. If none is available, open a brief issue asking for a private contact;
do not identify affected people or publish sensitive details in that request.
